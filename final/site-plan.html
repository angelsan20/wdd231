Life Tools Hub - Site Plan

Proyecto Final WDD231 | Desarrollado por Angel Santafé Palma

1. Site Name

Nombre del sitio: Life Tools Hub

Razón de selección: Este nombre representa una caja de herramientas digital multipropósito centralizada para estudiantes, desarrolladores y profesionales que necesitan organizar, gestionar y consultar recursos, enlaces y herramientas de utilidad diaria de forma eficiente.

Dominio disponible opcional: lifetoolshub.org

2. Site Purpose

El sitio web funciona como un centro de recursos y directorio interactivo ordenado por categorías prácticas (programación, desarrollo web, cocina, fitness y entretenimiento). Ofrece tarjetas informativas con vistas previas, un sistema local de favoritos mediante almacenamiento web y herramientas de importación/exportación de respaldos personalizados mediante archivos JSON.

3. Target Audience Scenarios

Preguntas clave que los usuarios se harán al visitar la plataforma:

  • ¿Cómo puedo guardar mis herramientas y enlaces favoritos sin perderlos al cambiar de computadora o limpiar el navegador?
  • ¿Puedo agregar una nueva categoría personalizada y mis propias páginas sin alterar el contenido base del sitio?
  • ¿Cómo puedo buscar rápidamente un recurso técnico específico o una guía dentro de las categorías disponibles?

4. Color Scheme

Inspirado en una estética de caja de herramientas industrial moderna y limpia, utilizando tonos neutros claros para evitar la fatiga visual y un acento amarillo brillante para llamadas a la acción.

Fondo General (#F9F9FB)
Contenedores / Tarjetas (#FFFFFF)
Texto Principal (#1E293B)
Acento Industrial (#F59E0B)

5. Typography

Se utilizará una única tipografía moderna, limpia y altamente legible de Google Fonts.

  • Tipografía Principal: Inter (Sans-serif)
  • Encabezados (H1, H2, H3): Inter Bold (700) o Semi-bold (600). Aplicada para dar jerarquía visual clara.
  • Cuerpo de texto y párrafos: Inter Regular (400). Aplicada para asegurar una lectura fluida en dispositivos móviles y de escritorio.
